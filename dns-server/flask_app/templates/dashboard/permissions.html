Access Levels

FULL Access
Complete read and write permissions
• Query DNS records
• Add/modify/delete records
• Manage zone settings
• View audit logs
READ Access
Query-only permissions
• Query DNS records
• View zone information
❌ Cannot modify records
❌ Cannot manage zones
DENY Access
No access permissions
❌ Cannot query records
❌ Cannot view zone info
• Returns NXDOMAIN (domain not found)

Selective DNS Routing

💡 How It Works
Selective DNS routing allows you to serve different DNS responses based on user identity and group membership. This enables a single DNS endpoint to provide:
  • Private corporate DNS to internal employees
  • Public DNS only to external users
  • Limited private DNS to partners/contractors
  • Different access levels based on group membership
Example Scenario
Query: intranet.company.com
INTERNAL group: Returns 10.0.1.50
EXTERNAL group: Returns NXDOMAIN
