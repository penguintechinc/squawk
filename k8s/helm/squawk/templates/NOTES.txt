=============================================================================
CONFIGURATION
=============================================================================

To configure selective DNS routing based on service/namespace:
1. Access the Manager API or Web Console
2. Create DNS zones with visibility settings (PUBLIC, INTERNAL, RESTRICTED)
3. Create groups with appropriate permissions
4. Assign user tokens to groups
5. The DNS agent will automatically forward source metadata with each request

Example: Configure internal-only DNS entries
  - Create zone: internal.company.com with visibility: INTERNAL
  - Create group: INTERNAL_USERS with zone access
  - Pods in authorized namespaces will resolve internal.company.com
  - Unauthorized pods will receive NXDOMAIN

   kubectl create secret tls {{ include "squawk.fullname" . }}-tls \
     --cert=path/to/tls.crt \
     --key=path/to/tls.key \
     -n {{ include "squawk.namespace" . }}

3. For monitoring, enable ServiceMonitor:
   --set metrics.serviceMonitor.enabled=true
